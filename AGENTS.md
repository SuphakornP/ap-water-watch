# AP Water Watch public source

- Preserve Thai-first typography, geographic monitoring, mobile usability and reduced motion.
- This public tree uses synthetic demo points and an OFL font. Keep original AP exports, AP font binaries, private bindings and credentials out of commits.
- Keep `.openai/hosting.json` neutral in this public repository. Local deployments use their own identity and configuration.
- Read real upstream payloads before changing normalizers. Never fabricate water measurements, historical series, flood extents or project ground elevations.
- Missing, stale and failed data are not normal/safe. Preserve nulls, source health and observation timestamps.
- Water status 1/2 means low water, 4 high water and 5 overbank. MSL is not project flood depth.
- Nearby-station screening is not hydrological connectivity. Retain triggering station/time/distance.
- Run tests, type checking and build for relevant code changes; inspect the browser for layout and interaction changes.
- Checklists are browser-local and do not represent shared operational completion.
- Preserve upstream licenses and public attribution.
- Keep the footer release version and developer credit in `lib/app-info.ts`; update the release version when publishing and keep both source editions consistent.
