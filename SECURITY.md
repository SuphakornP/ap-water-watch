# Security reporting

Please report vulnerabilities privately using [GitHub's Report a vulnerability form](https://github.com/SuphakornP/ap-water-watch/security/advisories/new).

Include the affected revision, reproduction steps, expected and observed behavior, and a minimal redacted proof of concept. Do not include active credentials, private project exports, or personal information. Avoid posting exploit details in a public issue before coordination with the maintainer.

The `main` branch is the currently maintained version. This is a monitoring prototype; the source repository does not provide hosted identity management or unattended emergency alert delivery. Deployers must configure their own access controls and operational supervision.
